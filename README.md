# 声音沙画

在屏幕上拖动作画，每一笔都会发出声音。越高越亮，越快越响。

一个纯前端小玩具：单个 `index.html`，没有依赖，不需要构建。

## 运行

直接用浏览器打开 `index.html` 即可。

> 浏览器要求用户先与页面交互才能播放声音，所以第一次按下画布时音频才会启动。

## 玩法

- **按住拖动**来作画，支持多指同时画
- **上下移动**改变音高：画布从下到上按所选音阶分成若干音区，左侧标有音名
- **左右移动**改变声像（声音在左右声道的位置）
- **移动越快**，音量越大、笔迹越粗
- 笔迹会在约 7 秒后消散，可以用「定格」保留

## 控制栏与快捷键

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 音阶 | `1`–`4` | 五声、小调、都节、全音 |
| 音色 | — | 玻璃、柔和、合成 |
| 定格 | `F` | 让笔迹不再消散 |
| 回放 | `空格` | 重新播放刚才画的内容（笔画间的长停顿会被压缩） |
| 清空 | `C` | 清除画布和录制内容 |
| 静音 | `M` | 开关声音 |
